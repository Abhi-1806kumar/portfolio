# Abhishek Kumar — Portfolio

React + Vite portfolio. Edit your details in:
- `src/data/profile.js` — name, bio, links, education, skills
- `src/data/projectsData.js` — your projects
- `public/resume.pdf` — your resume (add this file)
- `src/sections/Skills.jsx` — the interactive skill map nodes

## Run
```
npm install
npm run dev
```
Build: `npm run build`
